# GPCP 总体架构与开源选型（v0.1）

> 项目：面向基站的通用通信处理器（General-Purpose Communication Processor, GPCP）
> 架构：RISC-V CPU + CGRA 异构阵列
> 形态：本阶段为**纯仿真原型**，目标制式 **LTE + 5G NR 双模**，协议边界按常规 gNB 整机。
> 性质：科研原型（许可证约束宽松，但商用路径仍按宽松许可预留）。

---

## 1. 需求基线（已与需求方确认）

| 项 | 结论 |
|---|---|
| 阶段 | 纯仿真原型（Verilator + QEMU 协同） |
| 制式 | LTE (Rel-10/14) + 5G NR (Rel-15/16) 双模 |
| 边界 | 基站完整协议：L1 PHY + L2(MAC/RLC/PDCP) + L3(RRC) + F1/N3 接口，对接 5GC |
| CPU | 复用开源 RISC-V 核（不以自研 CPU 为目标） |
| CGRA | 8×8 PE 目标规格，16b MAC + 32b 累加，算子集见 §4 |
| CPU–CGRA 接口 | 共享 DDR + 描述符环 DMA，MMIO 下发任务；不扩展 CPU ISA |
| 许可 | 科研原型；研发期可用 AGPL 参考实现，商用路径改用宽松许可 |

## 2. 开源项目调研与选型

> 许可证以各仓库当前 `LICENSE` 为准；下表用于方向判断，落地前需复核。

### 2.1 协议 / PHY 参考实现

| 项目 | 语言 | 覆盖 | 许可 | 结论 |
|---|---|---|---|---|
| srsRAN_Project | C++17 | 5G NR gNB（CU/DU、PHY 结构清晰） | AGPL-3.0 | **主参考**：PHY 分层与 kernel 切分最贴近 CGRA 映射 |
| srsRAN_4G | C++11 | LTE eNB/EPC/UE | AGPL-3.0 | **LTE 主参考** |
| OpenAirInterface 5G | C | NR gNB/UE/核心网 | OAI Public License v1.1 | 仅阅读参考（构建重、耦合深） |
| free5GC | Go | 5GC（AMF/SMF/UPF…） | Apache-2.0 | **联调核心网**（商用友好） |
| Open5GS | C | 5GC/EPC | AGPL-3.0 | 备选，LTE EPC 联调方便 |
| UERANSIM | C++ | NR UE / gNB 仿真 | GPL-3.0 | 备选：端到端业务验证 |

**策略**：以 srsRAN_Project / srsRAN_4G 的**算法与接口定义**为蓝本，在 CGRA 上重写数据面 kernel；
控制面/协议栈代码在 RISC-V Linux 上以**进程边界隔离**方式复用（不静态链接 AGPL 代码到自研闭源模块）。

### 2.2 CPU 核

| 项目 | ISA | 特性 | 许可 | 结论 |
|---|---|---|---|---|
| CVA6 (Ariane) | RV64GC | 6 级乱序、可跑 Linux、生态成熟 | Solderpad 0.51（Apache 类） | **M2 主选**（协议栈跑 Linux） |
| Ibex | RV32IMC | 小而全、Verilator 友好 | Apache-2.0 | **M1 首选**（快速搭 SoC、裸机验证） |
| Rocket Chip | RV64GC | Chisel 生成器、生态完整 | BSD-3 | 备选 |

**分两段走**：M1 用 Ibex 把「CPU 真的通过 AXI 驱动 CGRA」跑通（迭代快）；
M2 换 CVA6 + Linux，把协议栈搬上来。两者共享同一套 CGRA 寄存器/ABI，切换成本低。

### 2.3 CGRA 与编译器

| 项目 | 作用 | 说明 |
|---|---|---|
| CGRA-ME | 架构探索 + 映射评估 | 用于 4×4 / 8×8、互连拓扑、位宽的量化对比（M2 起） |
| OpenCGRA | 开源 CGRA 生成/评估框架 | 作为架构参数与评估方法的参考 |
| CGRA-Flow | MLIR 到 CGRA 的编译流 | 作为 M3 编译器路线（MLIR dialect + 布局布线） |
| MLIR / LLVM | 通用编译基础设施 | Apache-2.0，长期编译路线底座 |

**M0 现实做法**：先自研一套**极简空间 VLIW 微码**（本文档 §3），保证「算法 → 阵列」手工可映射、
可验证；M2 起再引入 CGRA-ME / MLIR 自动映射，避免一上来被工具链拖死。

### 2.4 仿真基础设施

| 工具 | 用途 | 说明 |
|---|---|---|
| Verilator | RTL 仿真 | 已装（oss-cad-suite 5.035） |
| QEMU (riscv64) | 系统级/用户态软件仿真 | 已装 6.2；M2 增加自定义 CGRA 设备模型 |
| Yosys / iverilog | 综合与轻量仿真 | 已装，用于面积/时序粗估 |

## 3. 总体架构

```
                         ┌──────────────────────────── 基站整机（仿真原型） ───────────────────────────┐
  RF/DFE (ADRV9009 等)   │                                                                              │
  JESD204B/C  ──────────►│  DFE 前端 ──► CGRA 阵列（L1 PHY 数据面）──► 共享 L2 / DDR ──► RISC-V 簇       │
                         │  (DDC/CFR/DPD)     8×8 PE, 16b MAC             │            (L2/L3 控制面)     │
                         │                                                  │                 │             │
                         │                     AXI4 DMA 描述符环 ◄──────────┴─────────────────┘             │
                         │                                                                  │             │
                         │                                                        100GbE / F1 / N3         │
                         └──────────────────────────────────────────────────────────────────┼─────────────┘
                                                                                            ▼
                                                                                 5GC (free5GC)
```

### 3.1 引擎分工

| 功能 | 承载 | 依据 |
|---|---|---|
| OFDM 调制/解调（FFT/iFFT、CP） | CGRA | 规则、吞吐大、可流水 |
| 信道估计 / 均衡（LS、MMSE） | CGRA | 矩阵/向量密集 |
| MIMO 检测与预编码（含波束赋形） | CGRA | 复数矩阵乘 |
| LDPC / Polar 编解码 | CGRA（分段）+ CPU（控制） | 迭代/图结构，需专用调度 |
| 序列生成（PSS/SSS/DMRS）、相关检测 | CGRA | 滑动相关 = FIR 结构 |
| MAC 调度、HARQ、RLC/PDCP | RISC-V | 控制密集、分支多 |
| RRC / NAS / F1AP / NGAP | RISC-V (Linux) | 协议状态机、消息编解码 |
| OAM / 日志 / 配置 | RISC-V | — |

### 3.2 存储层次与带宽预算（NR 100 MHz，30 kHz SCS）

- 采样率 122.88 Msps，16 bit I/Q（4 B/样本）；
- 单天线原始 IQ：≈ 491.5 MB/s；
- 4T4R：≈ 2.0 GB/s；64T64R（上行为主）：≈ 31.5 GB/s — 必须分流：
  - 前端 DFE 内做通道级抽取/合并，CGRA 只处理**波束/流**级数据（典型 8~16 流）；
  - CGRA 侧使用 **分布式 scratchpad + 双缓冲 DMA**，避免全部走 DDR；
  - 目标：DDR 常驻流量 ≤ 4 GB/s（仿真阶段先以事务级模型统计）。

### 3.3 关键接口

| 接口 | 类型 | 说明 |
|---|---|---|
| CPU ↔ CGRA 控制 | AXI4-Lite | 任务下发、状态查询（M0 已实现） |
| CPU ↔ CGRA 数据 | AXI4 + 描述符环 | 输入/输出缓冲、乒乓、完成中断 |
| CGRA ↔ DFE | 流式（AXI-Stream 类） | 采样流、波束流 |
| 外部 | 100GbE | F1 / N3 / OAM |
| 同步 | PTP (IEEE 1588) | TDD 定时 |

## 4. CGRA 目标规格

| 参数 | M0（已实现） | 目标（M2/M3） |
|---|---|---|
| 阵列 | 4×4 | 8×8（可参数化到 16×16） |
| 数据位宽 | int16 MAC → int32 累加 | int16 / bf16 双模，可选 int8×4 |
| 互连 | N/E/S/W 最近邻 + 1 周期 link | + 对角线 / 2 跳 / 广播 |
| 本地存储 | 8×32b 寄存器 + acc | + 每 PE 256 B scratchpad |
| 指令 | 32b/PE/cycle（空间 VLIW） | 64b（双发射 + 谓词） |
| 控制 | 全局 PC 顺序执行 | 循环/分支加速、条件执行 |
| 数据入口 | 单一边界流端口 | 多路 AXI-Stream FIFO + DMA |

算子覆盖（按优先级）：
1. 复数 MAC / FIR / 滑动相关（已用 FIR16 验证）
2. FFT / iFFT（基数 2/4，16~4096 点）
3. 矩阵乘 / MMSE 均衡 / 预编码
4. LDPC min-sum、Polar SC/SCL
5. 向量超越函数（LUT 近似：log/exp/sqrt）

## 5. 软件栈映射

| 层 | 运行位置 | 复用来源 |
|---|---|---|
| PHY 数据面 kernel | CGRA 微码 | srsRAN PHY 算法重写 |
| PHY 控制/调度 | RISC-V Linux 用户态 | srsRAN PHY 控制部分 |
| MAC / RLC / PDCP / RRC | RISC-V Linux 用户态 | srsRAN gNB |
| F1 / NG 接口 | RISC-V Linux 用户态 | srsRAN CU + free5GC |
| 5GC | x86 侧（仿真原型） | free5GC |

驱动形态：`/dev/gpcp-cgra` 字符设备（UIO/VFIO 或自研 misc 驱动），提供 `ioctl` 下发任务、
`mmap` 共享 DMA 缓冲。

## 6. 主要风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 内存/磁盘不足（本机 7.7 GB / 33 GB 可用） | 大 RTL、OAI 无法本地全量构建 | 只用 srsRAN；CVA6 单配置；增量编译 |
| 编译/映射工具链成熟度 | CGRA 利用率低 | M0-M2 手工微码保底，M3 再上 MLIR |
| AGPL 污染 | 商用受限 | 进程边界隔离 + 自研数据面 |
| 64T64R 带宽 | DDR 打爆 | DFE 内合并 + scratchpad + 流式 |
| 时序收敛（8×8 全互连） | FPGA/ASIC 难收敛 | 分簇 + 局部互连 + 流水寄存器 |

---

## 7. 许可策略

- 研发期：允许**阅读/调用** AGPL 工具（srsRAN、Open5GS），但保持独立进程、独立二进制。
- 交付/商用：数据面与 RTL **全部自研**；核心网换 free5GC（Apache-2.0）；
  CPU 核使用 CVA6（Solderpad）/Ibex（Apache-2.0）/Rocket（BSD-3）。
- 所有第三方代码进 `third_party/`，不修改、不打补丁（必要时以 patch 文件形式记录）。
