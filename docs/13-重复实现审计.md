# 13. 重复实现审计（2026-11-06）

> 用 `tools/dup_audit.py` 扫出来的，不是目测。判定与数字都可复现：
> `python3 tools/dup_audit.py --min-lines 12 --top 14`

## 0. 结论

| 指标 | 数值 |
|---|---|
| 扫描函数 | **800 个** / 归一化后 **15758 行** |
| 重复簇 | **17 个**（exact 9 / near 8） |
| 冗余行数 | **≈1092 行（6.9%）** |
| 单点最贵 | `pdsch_full_bm.c` 与 `pusch_bm.c` 的 `main()` **80% 相同（192–198 行）** |
| 最广 | `mmio_r`/`mmio_w` **26 份**；`wait_desc` **17 份**；`gold_init`/`gold_bit` 各 **12 份** |
| Python | 34 个 checker / 4505 行，**共享库 0 个**；`parse()` 21 处（其中 6 处逐字节相同） |
| Makefile | 34 个 `run-*` 目标，平均 **9.4 行配方**，形状全部相同（dump → 构建 → 仿真 → check） |

**根因不是懒，是缺一层。** C 侧只有"生成的表头"（`*_prog.h`/`*_luts.h`），没有运行时公共件；
Python 侧 34 个 checker 零共享模块。于是**每加一个门，就复制上一个门**——34 个门 = 34 份仪式。
这已经不是"偶发复制"，而是把"加门"当成了手工作业而非产品化流程。

## 1. 先划清边界：哪些"重复"不是轮子

审计要能说"这些该留"，否则会把设计意图当债务砍掉：

- **自研 FFT / LDPC / polar / ZC**：项目目标就是把算法映射到 CGRA，自研是**交付物**；
- **裸机不用 libc**：`-nostdlib -ffreestanding`，没有 `printf`/`malloc`，重复的格式化代码是代价不是浪费；
- **每个基准自己的结果布局**（`out[1087]` 之类）：是硬件 ABI 的一部分，不该抽象；
- **生成的表**（`csi_cqi_tab.h`、`pusch_idft_tab.h`、`pdcch_luts.h`）：已经是"生成而非复制"，**这是正面样板**。

要治的是下面三类。

## 2. 三类重复

| 重复项 | 份数 | 位置 | 状态 |

| checker `parse()` | 6（`check_dma/fft/irq/ring/rxchain/slot`） | `tools/` | ✅ 本次已消除（`tools/checklib.py`） |

| `build_node_uc()` | 7 × 26 行 | SSB 家族 + pdcch + rach + link_e2e | 待做 |

### B 类：参数化重复（同算法不同常量，需要设计）

| 重复项 | 份数 | 差异 | 建议 |
|---|---|---|---|
| `gold_init` / `gold_bit` | 12 + 12 | LFSR 多项式相同，长度/`c_init` 不同 | `sw/include/nr_gold.h`：`gold_gen(x1,x2,len,c_init)` |
| `wait_desc` | 17 | 6 个变体，主流两版**只差一个 `dbg_wait++`** | `cgra_ring.h` + 返回码，调用点 3 行改成 4 行 |
| `build_tables` / `load_program` / `corr_one` / `build_corr_uc` | 3–5 各 | 环形初始化与微码装载 | 随 SSB 家族合并一起做 |

### C 类：结构性重复（最贵，收益也最大）

1. **`main()` 整段复制**：`pdsch_full_bm.c` ↔ `pusch_bm.c` 80%（~195 行）；
   `ssb_fft_bm.c` ↔ `ssb_slot_bm.c` 81%（148/165 行）——SSB 三兄弟另有 4 组完全相同的辅助函数。
2. **checker 骨架**：34 个文件、4505 行，21 个自带 `parse()`、28 个自带 `[FAIL]` 打印、14 个自带 argparse。
3. **Makefile 配方**：34 个 `run-*` 各 9.4 行，形状一模一样。

## 3. 已经开始漂移的证据（这是"必须治"的理由）

复制不会静止，它会各自演化——本项目已出现三处：

1. `sw/soc/cgra_bm.c` 的 `mmio_w` 用了 `u64/u32`，其余 26 份是 `uintptr_t/uint32_t` → **同一 ABI 两种写法**；
2. `gold_init` 有两种实现：一种调 `gold_fill()`，一种内联 16 行；`ssb_bm.c` 里甚至并存
   `gold_x1/x2` 与 `gold2_x1/x2` **两套状态**（`gold_init2`/`gold_bit2`）；
3. `check_pdsch_64qam.py` 是昨夜从 `check_pdsch_16qam.py` 复制改的（**88% 相同**）——
   我本人上一轮就在造轮子，说明这不是历史包袱，是当前工作方式。

**成本模型**：N 份副本 = 每次 ABI 变更要改 N 处。`mmio` 这次是 26 处 → 1 处。

## 4. 解法（按性价比排序）

| # | 方案 | 消除 | 风险 | 验证方式 | 工作量 |
|---|---|---|---|---|---|
| **1** | `sw/include/soc_io.h` 共享运行时头 | 26×2 行定义 | 低 | **二进制 md5 逐字节不变** | ✅ 已完成 |
| **2** | `tools/checklib.py`：`parse_dump()` + `words32()` | 6 份逐字节相同的 `parse` | 低 | ✅ 已完成，6 门复跑全绿 | 0.3 天 |
| **3** | `tools/new_gate.py` 脚手架：一条命令生成 bm.c + checker + Makefile 配方 + 注册 verify/cache | **未来所有新门** | 低 | 新建一个 demo 门跑通 | 0.5 天 |
| **4** | `sw/include/nr_gold.h`：`gold_gen()` 参数化 | 12×2 | 中 | 全量回归 + 位序列对拍 | 0.5 天 |
| **5** | `sw/include/cgra_ring.h`：`soc_wait_ring_done()` | 17×8 | 中 | 全量回归 | 0.5 天 |
| **6** | Makefile `$(call nr_bench,name,td,bin,check)` 宏 | 34×9.4 → 34×2 | **高**（配方是回归入口） | `verify.sh slow --force` 全绿 | 1 天 |

排序理由：#1 零风险已证；#2/#3 在 `tools/` 内，不动 RTL 与二进制，且 #3 从根上让"复制"失去必要性；
#4/#5 要动 12–17 个文件，值得但需一次全量回归兜底；#6 收益最大也最危险，放在有 #2/#3 之后。

## 5. 本次已实施：#1（并发现一个陈旧二进制）

- 新增 `sw/include/soc_io.h`，26 个基准删除本地定义、改为 include；
- `sw/soc/Makefile` 增加 `COMMON_HDRS` 静态依赖 → **改共享头必定重编全部 34 个程序**
  （不做这一步就会重演"改了头但跑旧二进制"，本项目已踩过两次）；
- `tools/verify_cache.py` 的 `GLOBAL_GLOBS` 加入 `sw/include/*.h` → smart 档同样失效重跑。

**验收证据**：
- 34 个程序全部重编、0 warning；
- **44/45 个 `.bin` 与重构前逐字节相同**；唯一不同的 `pdsch_bg2_bm.bin` 经对照实验证明是
  **构建目录里的陈旧产物**（用 HEAD 源码重编得到 `95d9af…`，与重构后一致），不是重构引入的差异。

顺带发现第 4 个"轮子"：**没有任何门使用 `pdsch_bg2_bm`**，它的 `.bin` 自上次无关构建后从未更新，
却一直躺在 `build/sw/` 里，很容易被误当成"当前版本"。建议在 `verify.sh` 的预构建里加一次
`make -C sw/soc all`（而非只构建门需要的），让陈旧产物无处藏身。

## 6. 已实施 #2：checker 共享库

- 新增 `tools/checklib.py`：`parse_dump()`（dump 格式的唯一定义）+ `words32()`（64→32 位展开）；
- 6 个逐字节相同的 `parse()` 删除，改为 `from checklib import parse_dump, words32`；
- 另一个 `check_*.py` 的 `parse()` 实现不同（少 `exit_code` 分支），**保持原样**——
  宁可少改，不可改错。

**验收**：6 个 checker 直接用回归产生的 dump 复跑，全部 `[ OK ]`，输出与迁移前逐字相同。
